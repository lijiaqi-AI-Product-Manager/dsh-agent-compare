# 界面语言 / Interface language

The bilingual interface is available from 1.2.0; 1.1.0 keeps its Chinese-only interface.

自 1.2.0 起，比较界面支持简体中文和英文。新对话和已有对话的右上角均可切换；设置默认跟随浏览器首选语言，手动选择保存在当前浏览器或桌面配置的本地存储中。语言切换不修改需求草稿、引用、模型设置、候选选择、代码或运行记录，也不重新启动比较与预览。浏览器拒绝存储时，本窗口仍可切换语言。

The comparison interface supports Simplified Chinese and English. Use the language selector beside history and tutorial in new or existing conversations. The default follows the browser's preferred language; an explicit choice is retained in local browser storage for that profile. Changing language preserves drafts, references, model settings, candidate choices, code and records. It does not restart comparisons or previews. When browser storage is unavailable, the current window still retains the choice in memory.

应用页面、用户需求、用户编写的验收步骤和候选说明保留原文。常见安装错误提供本地化的原因与处理建议；未知诊断以“原始诊断”明确标注并可用键盘展开，内容不会被推测性翻译替代。语言选择不额外请求模型。

Application pages, tasks, user-written acceptance steps and candidate explanations keep their original content. Common installation failures have localized explanations and recovery hints. Unrecognized diagnostics are labeled as original evidence and remain expandable by keyboard. They are not replaced with an inferred translation. Language selection makes no model requests.

The published package retains user recovery guides, package-manager guidance, icons and market screenshots. Detailed demonstration measurements and directory-maintenance notes stay linked from the repository instead of being repeated in every package download. Their source files and history remain available.

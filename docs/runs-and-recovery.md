# 运行记录与恢复

**中文** · [English](runs-and-recovery.en.md) · [快速上手](quickstart.md)

先在原对话的 A|B 卡片或右上角「比较记录」找到这次比较。记录保留需求、检查、选择和采用状态；选择候选还没有写入项目。

| 遇到的情况 | 下一步 |
| --- | --- |
| 预览停止或重启后没有网页 | 副本仍在时点「重新打开预览」；副本已释放则查看截图与源码补丁。 |
| 安装、验收或预览失败 | 先查看失败原因；符合条件时点「重新验收」，不重新生成。 |
| 采用预演耗时较长 | 在开始写入前点「停止采用预演」，等待进程退出。 |
| 采用、撤销或恢复被中断 | 按卡片标明的恢复目标处理，保留原始文件目录；不手动覆盖冲突路径。 |
| 提示另一个窗口持有比较 | 回到原窗口操作，或等其关闭后刷新；不要删除锁文件。 |
| 想释放磁盘空间 | 使用「副本空间」查看清单并确认释放；运行记录、补丁与撤销原件保留。 |

## 预览与历史

新建和已有对话的右上角均提供「比较记录」与「使用教程」，直接打开历史或指南，并保留宿主原有的角落控件。预览已停止时显示明确状态和已有截图；副本仍在则可以重新打开预览。

比较记录默认浏览全部对话，也可切换到当前对话。按需求、项目或运行编号搜索，每页显示 30 条并支持翻页；原始记录持续保留。列表中的旧版记录只读。安装后若界面提示服务端尚未更新，重启 DSH 再使用新控件。

## 重新验收

尚未选择结果时，安装、验收或预览阶段失败／中断的已封存候选可点「重新验收 A/B」。它复用原提交、补丁与验收定义，不再次调用生成模型；副本或补丁被改动时会拒绝。每次重试前归档上次的失败与检查，保留生成用量，记录当前验收宿主和包管理器版本。宿主环境与基线不同时会提示条件差异，缺少版本或耗时不会填成零。当前验收的耗时不包含历史空闲时间。

重新验收也占用运行名额，可单独停止，已完成的另一版继续保留。重启后仍可对保留且通过完整性检查的候选重新验收；已选择、采用、清理或锁文件不一致的结果不能这样重试。锁文件失败需要修正后开始新的比较，冻结安装不会被自动放宽。单份记录最多归档 100 次重试。

## 采用与恢复

历史可查看全部对话。选择、采用、撤销、停止、重新验收、重新打开预览或释放副本时，会先由宿主解析当前对话；操作其他对话的比较或无法确认所属对话的旧记录，需要核对项目、运行编号并确认本次操作。确认不会绕过宿主权限、运行归属锁或文件完整性核验。按 Esc 可取消确认并留在历史窗口；每项操作分别确认。

采用前若需要合并你后续的编辑，会在副本中预演。原对话的卡片可点「停止采用预演」，等待本次进程及子进程退出后回到已揭晓状态；候选源码、补丁与运行记录继续保留，可重新审查采用。若进程退出无法确认，会保留预演副本并阻止再次采用。开始保留原始文件和写入以后，停止入口会消失，需等待交接与核验完成。

直接采用会先保留实际原始文件，再交接候选；交接遇到新编辑或同路径新文件时会停止，保留双方内容。结果中的「查看保留内容的位置」列出项目内自忽略的 `.agent-compare-transfer-*` 目录。目录含原始项目内容和日志，不会随副本或预览清理；恢复结束前请勿删除，也不要把它作为公开演示素材上传。

中断可能发生在采用、撤销或旧记录恢复中。界面会区别「恢复到采用前」和「回退未完成操作」：后者回到上次撤销或恢复开始前，并可能仍需再恢复原采用。冲突路径不会被自动覆盖；请核对当前文件及保留内容后再处理。旧记录首次撤销或恢复也使用新的文件交接方式，但无法补回旧版本未保留的原始字节。

直接写回只支持普通文件、最多 10,000 个路径及合计 128 MiB 的原始与候选内容，并要求本地文件系统支持硬链接。限制不满足时会停止写回，可另存分支审查；不会回退到覆盖式写入。更新界面若仍连接旧后台，会阻止直接采用并提示重启 DSH。

## 项目检查与进程问题

构建输出按基线的 Git 忽略规则处理，不再一概排除名为 `dist` 的目录。项目使用自定义 Vite `build.outDir` 时，先将输出目录加入 `.gitignore`，再开始比较；Vite 配置和 `.gitignore` 会随基线绑定，包括已纳入快照的未提交编辑。已被 Git 跟踪的文件即使位于忽略目录内，也会继续检查。验收期间出现未忽略的新文件或已跟踪文件变化，会阻止采用，需要修正配置后开始新的比较；不会改写当前验收或悄悄删除这些文件。此项更严格的源码漂移检查自 1.1.0 起生效，历史记录保留其原始验收依据。

Windows 进程检查和终止辅助命令都有等待上限。无法确认整个任务进程树已停止时，记录会明确说明，保留候选或采用预演副本，并阻止对该副本重新验收或重复采用；重启也不会将它当成已经停止。请先检查该任务及其子进程，再按提示手动清理保留的副本。其他已完成候选仍可查看和选择。

## 释放空间

需要整理依赖和缓存时，使用[副本空间与确认清理](copy-cleanup.md)。此入口保留源码补丁、Git 引用及撤销原件，不自动过期删除记录。

升级前先结束活动比较并关闭旧版本实例。记录损坏或归属不明时保持只读，不会推断任务已停止。锁文件、旧格式、状态同步和保留资源的细节见[维护与资源保留](maintenance.md)。

`/ab <需求>` 保留为可选快捷方式。常用设置均在输入框上方完成。

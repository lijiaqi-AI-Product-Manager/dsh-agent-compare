# 维护与资源保留

**中文** · [English](maintenance.en.md) · [用户恢复指南](runs-and-recovery.md)

## 哪些资源会继续保留

| 资源 | 释放副本后的状态 | 用途 |
| --- | --- | --- |
| 依赖目录、可释放的候选副本和预览进程 | 只按确认后的归属清单释放 | 回收可重建的运行资源。 |
| 运行记录、封存补丁和截图 | 保留 | 查看历史、复核与后续采用。 |
| `refs/agent-compare/<run>/` 中的源码与采用前引用 | 保留 | 固定候选内容并支撑采用、撤销；不能等同于无用分支。 |
| DSH 候选会话与日志 | 保留 | 继续追溯生成过程和父子会话关系。 |
| 示例仓库 | 保留 | 它是比较与可能的采用目标，不只是缓存。 |
| `.agent-compare-transfer-*` 原件与交接日志 | 保留 | 恢复、撤销及冲突时保存双方字节。 |

「释放副本」不会自动删除这些历史材料，也没有七天到期删除规则。释放后仍可能占用磁盘；不要为了减少目录或 Git 引用数量删除撤销依据。需要删掉历史成果时，应先明确每次比较的采用、撤销与恢复状态，另行决定删除范围。

DSH 0.2.2-rc.1 的工作区注册、候选会话和首次历史迁移是不同机制。候选以子会话关系和自己的工作目录保存；不能仅凭会话目录数推断侧栏新增了相同数量的工作区。宿主的会话归档用于隐藏分组条目，并不删除日志或释放其磁盘占用；插件不代替用户自动归档。工作区首次迁移可能按已有会话目录建立分组，应与正常使用后的注册状态分别核对。

## 归属、恢复与版本边界

1.1.0 新增停止预演、跨对话操作确认及当前状态同步；1.0.1 不包含这些更新。[本次状态同步记录](https://github.com/lijiaqi-AI-Product-Manager/dsh-agent-compare/blob/main/docs/measurements/current-context-2026-11-05.json)区分安装源码、实际上下文与模型回答；两次请求来自同一个受控比较，并不代表所有模型的可靠率。

主对话组装模型上下文时，会附上该对话最近更新的比较状态，包含运行编号、记录修订、选择、采用方式与采用状态。它会明确覆盖同一次比较的旧状态说明，区分「已选择」「写入工作区」「另存分支」和「已撤销」。历史说明仍保留；候选对话和没有实际请求的空闲对话不附加这份状态，读取失败时会注明当前状态未知。

重启后打开旧对话的比较设置，会通过 DSH 的会话域恢复原会话，不发送模型消息，也不另建对话。并发读取共享恢复过程；取消一条请求不会取消另一条请求，仍遵守宿主的会话权限。

格式不完整、不兼容、无法读取或超过 16 MiB 的记录会标为「需处理」，说明原因并保留原文件，不阻塞其它正常记录。可勾选「只看需处理」查找；不会依据这些记录操作项目文件或进程，过期更新也不会覆盖损坏记录。

正在管理比较的宿主持有运行归属。其它同版本宿主共享本地记录时，仍可查看历史、源码改动和真实预览；选择、停止、采用和清理保持只读，直到原宿主关闭，界面会自动刷新归属。正常关闭会先等待已接受的工作退出；进程崩溃后，SQLite 连接锁由系统释放，新宿主再恢复孤立记录。采用、撤销与写入恢复还在 Git 公共目录中共享仓库锁，覆盖不同插件数据目录和链接工作区。

已经打开的另一个宿主，在打开、刷新记录或取得操作归属时也会恢复孤立记录：生成标为中断，核验后清除已停止预览的旧地址，写入中断则显示采用恢复操作；无法确认归属或清理状态的资源会保留并说明原因。仍有活跃所有者的比较和无归属凭据的旧记录保持原样。卡片同时核对运行编号和修订，延迟响应不会把已选择或已采用的结果改回旧状态。状态工具只允许主对话调用，候选不能借它恢复其它比较的资源。

升级前先完成或清理活动比较，并关闭所有旧版本实例；不支持不同插件版本并发修改同一份记录。新记录带协调标记，alpha.9 会将它保留为不可操作的只读记录，更早版本不识别这条边界。旧记录若缺少归属凭据且仍可能有活动资源，当前版本只提供查看，不推断任务已经退出。旧 `.lock` 目录会保留并阻止对应操作，需要在旧实例停止后检查。SQLite 锁文件必须保留在本地文件系统上，暂不支持网络共享目录锁。

比较任务通过宿主命令执行器进入会话日志，卡片按运行编号读取同一份持久记录。结果、选择、采用或撤销会形成模型可读说明，在所属对话下一次请求的 `agent/pre-step` 中写入，并按会话记录去重；请求在提交前被取消时，下一次请求会补上。说明明确标出目标仓库，避免把示例结果误认为原项目的改动。详见[主对话记忆与上下文](conversation-memory.md)。

模型也可以自己调用 `agent_compare_start` 工具（参数：`task`，可选 `time_limit_minutes`），对话里显示同样的 A|B 卡片。

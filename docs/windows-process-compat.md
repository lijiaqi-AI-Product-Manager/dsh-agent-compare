# Windows 进程兼容

[English](windows-process-compat.en.md)

这项功能自 1.2.0 起提供；1.1.0 没有下面的设置入口。

在 Windows 的 A|B 设置条中展开「Windows 高级设置」，可以选择「自动（推荐）」或「关闭兼容层」。选择会保存在当前对话；开始比较时，设置会与公共验收条件一起封存。之后更改设置不会改变已有候选、采用预演或历史预览的执行条件。

自动模式为当前宿主受限进程提供 esbuild 服务管道、版本探测与 Vite 可选网络盘探测的适配。关闭模式不注入这些预加载入口，也不继承它们的激活开关。宿主进程约束、锁文件冻结安装、生命周期脚本许可和项目检查始终保留；不会自动改用其他执行权限、版本或安装方式。关闭后部分工具链可能失败，原候选仍可保留供检查。

揭晓后，「检查依据与用量」分别显示配置模式与已观察到的钩子。记录来自项目进程的诊断输出，不构成隔离证明；「未观察到」也不表示某个钩子不可能触发。盲选期间不下发这些实现信号。旧记录没有相关字段时，不补写推测结果。

如果怀疑某个工具链与适配层冲突，可保留当前结果，在下一次比较前切换模式。记录中的配置随比较封存，不能在重新验收或采用期间悄悄改变条件。

这项开关不能解决 Windows pnpm 12 的系统操作锁写入要求，也不代表 TypeScript 7 已支持 Yarn PnP。相应限制仍见[分发与兼容说明](distribution.md)。

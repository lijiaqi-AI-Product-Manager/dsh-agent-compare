# 快速上手

**中文** · [English](quickstart.en.md)

1. **安装并打开项目。** 按[完整指南](../README.md#install)安装 `dsh-agent-compare`，需要时重新加载 DSH。已有配置和模型直接复用；准备至少有一次提交、根目录为 Vite 应用的本地 Git 仓库。
2. **点 A|B，只写需求。** 输入框上方选择比较方式、两个已配置模型（可选）和每版时长；也可直接点「试跑内置示例」，它会新建独立商店仓库。无需输入参数。
3. **实际体验，再选择。** 对话卡片显示两版应用、状态与共同验收。两版分别消耗模型用量；用量缺失显示未知，超时不代表改动已满足要求。
4. **审查采用。** 选择后查看身份、差异和检查，确认目标项目后采用；有后续编辑时会检查并预演。采用成功后可继续在主对话提出修改，或按卡片撤销。

同一模型模式比较两种策略，不是两个不同模型。选择与采用是两个步骤。内置示例结果写入示例项目，不会自动写回原项目。

项目不受支持、预览停止或采用中断时，先看[运行记录与恢复](runs-and-recovery.md)；需要回收依赖目录时看[副本空间](copy-cleanup.md)。当前发布包与主分支的已交付范围，以完整指南的版本说明和兼容表为准。

# 快速上手

**中文** · [English](quickstart.en.md)

1. **安装并打开项目。** 按[完整指南](../README.md#install)安装 `dsh-agent-compare`，需要时重新加载 DSH。已有配置和模型直接复用。任何目录都能开始；非 Git 目录从私有空白工作区开始，现有文件不会自动读入。见[目录与项目类型](workspaces-and-projects.md)。
2. **点 A|B，选版本数和风格，写需求。** 在输入框上方选择：
   - 比较方式；
   - 版本数（2–4 版）；
   - 盲选或公开对比；
   - 每版的[风格](../README.md#styles)，或每版各用一个已配置的模型；
   - 每版时长。

   也可以直接点「试跑内置示例」，它会新建一个独立的商店仓库。无需输入参数。
3. **实际体验，再选择。** 对话卡片会显示每一版的回答、文件或实时网页，以及状态和适用的共同验收。3–4 版时，可以先「排除」已经不考虑的版本；在卡片里按 1–4 键可以专注某一版。每版各自消耗模型用量；用量缺失时显示未知，超时也不代表改动已满足要求。
4. **选择、审查、采用。** 盲选时，选择后才揭晓风格和模型；公开对比一开始就显示。选完可以点几个理由（布局、配色、交互……）或补一句，主对话接着修改时会保留这些优点。确认差异、检查结果和目标项目后再采用；如果之后有新的编辑，会先检查并预演。采用成功后，可以在主对话里继续提修改，或者在卡片上撤销。

同一模型模式比较的是不同风格，不是不同模型。选择与采用是两个步骤。内置示例的结果写入示例项目，不会自动写回原项目。

预览停止或采用中断时，先看[运行记录与恢复](runs-and-recovery.md)；需要回收依赖目录时看[副本空间](copy-cleanup.md)。当前发布包与主分支的已交付范围，以完整指南的版本说明和兼容表为准。
